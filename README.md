# Inicio TV

Pantalla de inicio simple para Android TV: fondo del día, reloj, clima, apps de streaming y acceso directo al HDMI de la PlayStation.

Instalar en la tele con la app Downloader: `ramiroagi.github.io/tv/i.apk`

Compilar: `bash build.sh` (deja el instalador en `salida/Inicio.apk`).
